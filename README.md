# Компьютерные сети

Добро пожаловать в репозиторий курса «Компьютерные сети»! Здесь собраны материалы лекций, домашние задания, практические работы и экзаменационные билеты, выполненные в рамках изучения дисциплины.

## О курсе
Курс охватывает основы построения сетей — от физического уровня и IP-адресации до настройки прикладных сервисов (HTTP, HTTPS, DNS, DHCP) и маршрутизации. Основной упор делается на практическое моделирование сетей в Cisco Packet Tracer и выполнение расчётных заданий.

## Как устроен репозиторий

- **`CM/`** — материалы по самостоятельным работам (СМ). Содержит документы с выполненными заданиями (например, `Саша_Деффо_СМ.docx`).
- **`exam/`** — материалы для сдачи экзамена/зачета. Здесь находятся файлы схем Packet Tracer (`.pkt`) и готовые отчеты по билетам (например, `билет_10_Саша_Деффо.pkt` и `Отчёт_билет10_саша_деффо.docx`).
- **`homework/`** — домашние задания, разбитые по занятиям.
  - `lesson_2` и далее (`lesson_3`, `lesson_4`...) — папки с выполненными домашними заданиями к соответствующим урокам (файлы `.md`, `.docx` и др.).
  - `theory` — теоретические материалы к занятиям.
  - `practice` — практические задания и скриншоты (например, `Безымянный.png`).
- **`lesson_2/`** — материалы для лекционных/практических занятий (например, презентация `Модели (4).pptx`).

## Инструменты
- **Cisco Packet Tracer** — для моделирования топологий, настройки VLAN, NAT/PAT, DHCP и DNS.
- **Git / GitHub** — для хранения и версионирования выполненных работ.

## Как использовать материалы
1. Скачайте репозиторий (или сделайте `git clone`).
2. Для просмотра сетевых схем откройте файлы `.pkt` в программе Cisco Packet Tracer.
3. Текстовые отчёты, лекции и решения доступны в форматах `.docx`, `.pptx` и `.md`.
